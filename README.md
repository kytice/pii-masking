# PII Masking Tool

A local, offline tool for detecting and reversibly masking personally identifiable information (PII) in Irish-context documents. Built as a Final Year Project.

---

## What it does

The pipeline detects PII across several categories, groups co-referring mentions together (e.g. "Aoife Murphy" and later "she"), and replaces each group with a consistent synthetic identity. The masked text can be used safely in LLM workflows; the mapping table allows restoration.

**Detected PII types**

| Label | Examples |
|---|---|
| `PERSON` | Aoife Murphy, Patrick, Paddy |
| `EMAIL` | aoife@example.ie |
| `PHONE` | 087 123 4567, +353 1 555 0198 |
| `EIRCODE` | D06 F2H3, H91 X4K7 |
| `PPS_NUMBER` | 1234567T |
| `IBAN` | IE29 AIBK 9311 5212 3456 78 |
| `CREDIT_CARD` | 4532 1488 0343 6467 |
| `IP_ADDRESS` | 192.168.0.1 |
| `USERNAME` | /Users/aoife |
| `API_KEY` | AWS / GCP key prefixes |

Detection combines a spaCy transformer NER model, a curated Irish-name gazetteer, regex patterns, and fastcoref coreference resolution.

## Project layout

```
src/
  detector.py        # NER + regex + gazetteer detection
  coref_resolver.py  # Coreference resolution (fastcoref)
  entity_merger.py   # Merges NER entities and coref chains into groups
  masker.py          # Replaces each group with a synthetic identity
  app.py             # Streamlit web UI
  main.py            # CLI demo / smoke test

data/
  irish_given_names.txt          # Full CSO given-names list (gazetteer)
  irish_given_names_male.txt     # Male-only subset (for gender inference)
  irish_given_names_female.txt   # Female-only subset
  ambiguous_names.txt            # Names that are also common words
  eircode_prefixes.txt           # Valid Irish routing-key prefixes

tests/
  test_detector.py
  test_masker.py

evaluation/
  evaluate.py                    # Precision/recall evaluation scripts
```

## Setup

**Requirements:** Python 3.10+

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

The `en_core_web_trf` spaCy model and the fastcoref model are downloaded automatically on first run. No data is sent to any external server after that — everything runs locally.

---

## Usage

### Web UI

```bash
cd src
streamlit run app.py
```

Open the URL shown in the terminal (usually `http://localhost:8501`). Paste text or load the built-in sample, toggle PII categories in the sidebar, then click **Run masking**.

### CLI demo

```bash
cd src
python main.py
```

Runs the full pipeline on a hard-coded sample and prints detected entities, coreference chains, and the masked output.

## Pipeline overview

```
Input text
    │
    ▼
PIIDetector          ← spaCy NER + Irish-name gazetteer + regex patterns
    │
    ▼
CoreferenceResolver  ← fastcoref (links pronouns and aliases to the same person)
    │
    ▼
EntityChainMerger    ← combines NER entities and coref chains into unified groups
    │
    ▼
PIIMasker            ← replaces each group with a consistent synthetic identity
    │
    ▼
Masked text + mapping table
```

Each PERSON group gets a gender-matched fake name generated by Faker, using CSO-registered Irish first names to infer gender. All other PII types are replaced with fixed tokens (e.g. `[EIRCODE]`, `[IBAN]`).
